# حلّها — الكسور المتكافئة

## العناوين المعتمدة
- تحدي تبسيط الكسور
- بطلات تبسيط الكسور
- عنوان المتصفح: حلّها — تبسيط الكسور الاعتيادية
- الشريط العلوي: تبسيط الكسور الاعتيادية

## التشغيل
```bash
npm install
npm start
```

ثم افتحي:
http://localhost:3000

## الأصوات
انسخي الملفات الأصلية التالية إلى مجلد `audio`:
- lobby.mp3
- start.mp3
- winner.mp3

الأصوات تعمل من جهاز المعلمة فقط.
