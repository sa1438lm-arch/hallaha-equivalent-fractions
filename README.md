# حلّها — تبسيط الكسور الاعتيادية

لعبة صفية تفاعلية عربية (RTL) للصف الخامس، تعمل بجلسة معلمة ومجموعات طالبات في الوقت الحقيقي.

## التشغيل
```bash
npm install
npm start
```
ثم افتحي: http://localhost:3000

## الصوت
ضعي الملفات التالية داخل مجلد `audio` مع الحفاظ على الأسماء:
- `lobby.mp3` — انتظار انضمام المجموعات (تكرار تلقائي)
- `start.mp3` — عند بدء التحدي
- `winner.mp3` — عند النتيجة النهائية

الأصوات تعمل على جهاز المعلمة فقط. زر **اختبار** في أسفل الشاشة يساعد على تفعيل الصوت في المتصفحات التي تمنع التشغيل التلقائي.

## التصميم المتجاوب
- بروجكتر وشاشات عريضة: لوحة متابعة المجموعات بجانب السؤال.
- لابتوب وآيباد: تتحول لوحة المتابعة إلى أسفل السؤال.
- جوال: تخطيط عمودي وأزرار بعرض مناسب للمس.

## النشر على Render
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
